# 재생 대본: 제로 탄산, 1부 컨셉 만들기 (검토용 2판, 2026-11-20)

화면의 뼈대를 만드는 동안 진짜 칠성이 대신 흘려보내는 대본이다. **숫자는 모두 견본이다**(실제 자료에서 계산한 값이 아니다). 화면에는 "견본 대화"라고 표시된다. 승인되면 같은 내용을 `zero-soda.json`으로 옮긴다.

2판에서 바뀐 것(참가자의 검토, 2026-11-20)

- **일을 두 부분으로 나눴다.** 1부 컨셉 만들기(아이디어 회의 → 컨셉 보드), 2부 매대 테스트(매대 테스트 → 테스트 결과 → 개선안 테스트 → 결과 보고서). 이 대본은 1부만 다룬다. 2부는 참가자와 상의한 뒤에 만든다.
- 처음에 무엇을 하는지와 전제(세븐일레븐 음료 매대)를 말한다. 무엇을 검토할지 모르면 그것부터 묻는다.
- 아이디어끼리 무엇이 다른지를 정해진 칸(맛, 용기와 용량, 특징)으로 보인다.
- 컨셉은 제품이 다른 것만 나눈다. 가격만 다른 것은 컨셉으로 나누지 않는다.
- 버튼과 확인 카드에 설명 한 줄을 붙인다.

재생은 기획자가 무슨 말을 하든 다음 차례를 내보낸다. 아래 "기획자"는 칩과 버튼만 눌렀을 때의 말이다. `·` 뒤는 덧말(작은 회색 글씨)이다.

## 첫 화면 (위쪽 전환으로 일을 고른다. 서버가 아니라 화면이 갖는 글이다)

위쪽 가운데의 전환: **컨셉 만들기** | 매대 테스트. 처음에는 컨셉 만들기가 골라져 있다.

컨셉 만들기를 골랐을 때
- 인사: 안녕하세요, 상품기획팀 칠성이예요. / 어떤 신제품을 생각하고 계세요?
- 인사 아래 작은 한 줄: 아이디어부터 컨셉 보드까지 같이 만들어요.
- 칩: 신제품 아이디어 내기 / 매대 빈자리에서 찾기
- 입력창 안내 글: 예: 제로 탄산 신제품을 검토하고 싶어요

매대 테스트를 골랐을 때
- 인사: 안녕하세요, 상품기획팀 칠성이예요. / 어떤 컨셉을 매대에 올려 볼까요?
- 인사 아래 작은 한 줄: 가상 소비자가 세븐일레븐 매대에서 고르는지 봐요.
- 확정한 컨셉 카드(견본 2장): 라임 제로 캔 · 페트 — 확정한 컨셉 2개 · 11월 20일 / 저당 과일 에이드 — 확정한 컨셉 1개 · 11월 17일
- 확정한 컨셉이 없을 때: 아직 확정한 컨셉이 없어요. 컨셉 만들기에서 먼저 만들거나, 가진 컨셉을 아래에 적어 주세요.
- 입력창 안내 글: 가진 컨셉을 직접 적어도 돼요
- 카드를 누르거나 글을 보내면: 매대 테스트는 아직 준비하고 있어요. (2부는 상의한 뒤에 만든다)

## 아이디어 회의

**기획자**: 신제품 아이디어 내기

**차례 1**
- 작업대: **기획 브리프** (5개 중 1개 정함)
  - 제품: 칠성이가 묻고 있어요
  - 채널: 세븐일레븐 음료 매대 · 지금은 이 매대의 상품과 가격을 알고 있어요
  - 타깃: (비어 있음) / 음용 상황: (비어 있음) / 핵심 니즈: (비어 있음)
- 칠성이: 좋아요, 아이디어부터 컨셉 보드까지 같이 만들어요. 다섯 가지를 정하면 아이디어를 낼 수 있어서, 오른쪽 기획 브리프에 하나씩 채울게요. 먼저, 어떤 음료를 생각하세요?
- 칩: 제로 탄산 · 매대에 9개 있어요 / 커피 · 매대에 12개 있어요 / 차 · 매대에 7개 있어요 / 칠성이가 골라 줘

**기획자**: 제로 탄산

**차례 2**
- 하는 일: 세븐일레븐 음료 매대를 보고 있어요
- 작업대: 기획 브리프 (5개 중 2개 정함) — 제품: 제로 탄산 / 타깃: 칠성이가 묻고 있어요
- 칠성이: 세븐일레븐 음료 매대를 봤어요. 제로 탄산이 9개인데 500ml 페트는 하나뿐이에요. 누구에게 팔지에 따라 아이디어가 달라져요. 타깃은 누구로 볼까요?
- 칩: 20대 직장인 · 당을 신경 쓰는 사람 82% / 30~40대 직장인 · 오후에 가장 많이 마셔요 / 칠성이가 골라 줘

**기획자**: 20대 직장인

**차례 3**
- 작업대: 기획 브리프 (5개 중 3개 정함) — 타깃: 20대 직장인 / 음용 상황: 칠성이가 묻고 있어요
- 칠성이: 20대 직장인으로 볼게요. 이분들은 오후에 일하다가 혼자 마실 때가 가장 많아요. 이 상황으로 잡을까요?
- 칩: 오후에 일하다가 · 34% / 점심 식사와 함께 · 21% / 상황은 정하지 않기

**기획자**: 오후에 일하다가

**차례 4**
- 하는 일: 아이디어를 내고 있어요
- 작업대: 기획 브리프 (5개 모두 정함) — 음용 상황: 오후에 일하다가, 혼자 / 핵심 니즈: 당 걱정 없이 기분 전환 · 칠성이가 골랐어요
- 작업대: **아이디어** — 도출 근거: 오후에 일하다가 마시는 20대 직장인은 "당 걱정 없이 기분 전환"을 가장 바라요

  | | 이름 | 맛 | 용기와 용량 | 특징 | 한 줄 | 다른 안과의 차이 |
  |---|---|---|---|---|---|---|
  | A | 제로 라임 스파클링 캔 | 라임 | 캔 355ml | 당 0, 카페인 없음, 탄산 | 한 손에 들고 한 번에 마셔요 | 셋 중 가장 작아요 |
  | B | 제로 라임 스파클링 페트 | 라임 | 페트 500ml | 당 0, 카페인 없음, 탄산 | 책상에 두고 오후 내내 나눠 마셔요 | A와 용기와 용량만 달라요 |
  | C | 제로 자몽 스파클링 페트 | 자몽 | 페트 500ml | 당 0, 카페인 없음, 탄산 | 쌉쌀해서 단맛 없이 개운해요 | B와 맛만 달라요 |

- 칠성이: 이 상황의 20대 직장인이 가장 바라는 건 "당 걱정 없이 기분 전환"이에요. 이 니즈로 아이디어 세 개를 냈고, 맛과 용기가 달라요. 컨셉으로 만들 것을 골라 주세요.
- 칩(여럿 고르기): A 제로 라임 스파클링 캔 · 라임, 캔 355ml / B 제로 라임 스파클링 페트 · 라임, 페트 500ml / C 제로 자몽 스파클링 페트 · 자몽, 페트 500ml

## 컨셉 보드

**기획자**: A 제로 라임 스파클링 캔, B 제로 라임 스파클링 페트

**차례 5**
- 단계: 컨셉 보드
- 하는 일: 컨셉 보드를 만들고 있어요
- 작업대: **컨셉 보드** (약속 v1.4의 모양. 경쟁 제품은 매대 자료의 실제 이름과 가격이고, 가격과 나머지는 견본이다)

  예시 시안

  | | 컨셉 A | 컨셉 B |
  |---|---|---|
  | 상황 한 줄 | 오후 세 시, 당 없이 한 캔 | 책상 위의 기분 전환 |
  | 제품명 | 라임 제로 캔 | 라임 제로 페트 |
  | 혜택 한 줄 | 한 번에 마시고 자리로 돌아가요 | 뚜껑을 닫아 두고 오후 내내 마셔요 |
  | 이런 점이 좋아요 1 | 당 0g | 당 0g |
  | 이런 점이 좋아요 2 | 라임 향 | 라임 향 |
  | 이런 점이 좋아요 3 | 강한 탄산 | 다시 닫는 뚜껑 |
  | 가격과 용량 | 1,500원 (355ml 캔) | 2,000원 (500ml 페트) |

  제품 특징(값 안의 줄바꿈은 / 로 적었다)

  | | 컨셉 A | 컨셉 B |
  |---|---|---|
  | 제품 유형 | 제로 탄산 | 제로 탄산 |
  | 맛 | 라임 | 라임 |
  | 용기와 용량 | 355ml 캔 | 500ml 페트 |
  | 당, 카페인 | 당 0g, 카페인 없음 | 당 0g, 카페인 없음 |
  | 탄산 | 강함 | 보통 |
  | 타깃 | 20대 직장인 | 20대 직장인 |
  | 음용 상황 | 오후에 일하다가 | 오후에 일하다가 |
  | 판매 채널 | 세븐일레븐 음료 매대(냉장) | 세븐일레븐 음료 매대(냉장) |
  | 목표 판매가 | 1,500원 | 2,000원 |
  | 경쟁 제품 | 칠성사이다 캔 355ml 2,100원 2+1 / 펩시콜라 캔 355ml 2,100원 1+1 | 칠성사이다 제로 페트 500ml 2,500원 1+1 / 펩시 제로슈거 라임 페트 500ml 2,500원 1+1 |
  | 차별점 | 당 0g에 라임 향 | 오후 내내 나눠 마시는 라임 향 |

- 칠성이: 고른 아이디어 두 개를 컨셉으로 만들었어요. 가격은 매대의 비슷한 제품을 보고 잡았어요. 고칠 곳이 있으면 말해 주세요.
- 버튼: **컨셉 확정하기** · 이 두 컨셉으로 정해요 / 가격 바꾸기 · 컨셉의 가격을 다시 정해요 / 컨셉 더 만들기 · 남은 아이디어도 컨셉으로 만들어요

**기획자**: 컨셉 확정하기

**차례 6**
- 요약 카드: 확정한 컨셉 — 2개 · 라임 제로 캔, 라임 제로 페트
- 칠성이: 컨셉 두 개를 확정했어요. 여기까지가 컨셉 만들기예요. 다음은 이 컨셉을 세븐일레븐 매대에 올리고, 가상 소비자가 고르는지 보는 매대 테스트예요.
- 버튼: **매대 테스트로 넘어가기** · 두 컨셉을 가상 매대에 올려요 / 컨셉 보드 내려받기 · 한 장으로 저장해요

## 대본이 끝난 뒤

- 칠성이: 매대 테스트는 아직 준비하고 있어요. 이 견본 대화는 여기까지예요.
